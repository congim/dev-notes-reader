# 使用指南

适用于 Dev Notes Reader 0.5.1。命令分类前缀为 **Dev Notes Reader:**；用 `Ctrl+Shift+P`（macOS 为 `⌘⇧P`）打开命令面板。

## 导入与书架

执行“导入并阅读本地文本”可导入并打开一本书。成功后使用当前阅读模式，新安装默认随行阅读。文件名用于书架显示，内容不会复制进项目。

点击活动栏书本图标，主动打开书架，再点“＋”可一次选择多个文件。批量导入只添加记录，不打断当前阅读；重复路径跳过，保留已有进度。部分失败不影响其他文件，通知中的“查看失败项”会列出路径与具体原因。

只支持可解码的纯文本，每个文件上限 20 MiB。选择器默认筛选 `.txt`、`.md`、`.text`；Markdown 不渲染排版。EPUB、PDF、压缩包或二进制文件需先用其他工具转换为纯文本。

书架按最近阅读排序，未读书排在已读书之后。每行显示百分比、书签数和当前书标记；悬停可查看完整路径与最近阅读时间。

| 操作 | 结果 |
| --- | --- |
| 点击书籍或“继续阅读” | 读取原文件，恢复该书位置 |
| 右键“修改书籍显示名称” | 仅修改书架名称；最多 80 字符，留空恢复文件名 |
| 右键“在文件管理器中定位” | 在 Finder 或系统文件管理器中定位原文件 |
| 右键“从书架移除书籍” | 确认后清除该书记录和书签，保留原文件 |
| 点击刷新 | 重新检查文件可用状态并刷新显示 |
| “快速切换书籍” | 在可输入筛选的列表中选择书籍 |

文件不可用时，记录仍保留。放回原路径后刷新并重试；改用新路径重新导入会作为另一条记录。重新打开时若内容摘要变化，该书的位置和书签会重置，显示名称保留。

## 阅读模式

从书架右上角 `…` 或命令面板执行“选择阅读模式”。

| 模式 | 展示位置 | 翻页单位 |
| --- | --- | --- |
| 随行阅读 | 当前代码文件光标附近的行末装饰 | 实际显示的正文行数 |
| 状态栏 | VS Code 右下角短句，点击可读下一段 | 一行 |
| 注释页 | 只读 `review-notes.ts` 虚拟标签 | 配置的注释页行数 |

随行文字不会写入源码、源码复制内容或 Git 差异。光标、输入和滚动只改变显示位置，不自动翻页。Python、Shell、Ruby、YAML 和 PowerShell 使用 `#` 前缀，其余语言使用 `//`。短文件或可见代码行不足时减少正文行数；没有合适的代码编辑器时暂时使用状态栏。

行末对齐按等宽字符和 Tab 计算。超长行、宽字符或折行可能让正文移出视野，此时缩短每行字数或切换状态栏。注释页是虚拟文档，不会在项目内创建同名文件。

## 章节、搜索与书签

- **章节目录**：点击阅读状态栏中的“目录”或执行同名命令。列表标记当前章，输入标题或序号可筛选，Enter 跳转，Esc 取消。隐藏时主动打开目录会恢复阅读；没有书籍时先导入。支持常见中文章节、`Chapter 3` 和 Markdown 标题，特殊排版可能识别不全。
- **上一章 / 下一章**：按标题位置跳转；在章内执行上一章会先回到本章标题。
- **全文搜索**：对整本书进行区分大小写的字面搜索，不执行正则表达式。关键字最多 200 字符；单个匹配直接定位，多个匹配最多展示前 200 个结果。
- **跳转进度**：输入 0–100 的百分比，支持小数。定位到包含目标字符的正文行，实际百分比可能略有不同。
- **添加书签**：给当前位置命名，名称为 1–80 字符。同一位置再次添加会更新名称。“查看书签”用于跳转，“删除书签”用于移除选中的书签。

## 图形设置

点击书架齿轮或执行“打开阅读设置”。设置作用于 VS Code 用户配置，无需编辑 JSON。界面标题从配置键生成，例如 `Inline Lines`，下方提供中文说明。

| 设置键 | 默认值 | 范围 / 作用 |
| --- | --- | --- |
| `devNotes.inlineLines` | 6 | 1–12，随行阅读正文行数 |
| `devNotes.lineLength` | 28 | 8–80，每行字数，三种模式共用 |
| `devNotes.pageLines` | 12 | 3–40，注释页每页行数 |
| `devNotes.hideOnBlur` | true | 切换窗口时隐藏，返回后需主动恢复 |
| `devNotes.encoding` | auto | `auto`、`utf-8`、`gb18030`、`utf-16le`、`utf-16be` |

行数和字数修改后即时重新排版，尽量保持当前字符位置。阅读模式通过“选择阅读模式”切换并独立保存，不在上述五项设置中。

`auto` 先检查 BOM，再尝试 UTF-8，失败后尝试 GB18030。GBK 中文文本通常可以使用 GB18030 读取。编码修改后需重新打开书籍或执行单书导入；批量导入会跳过已有路径。若重新解码后的正文改变，会重置该书进度和书签。

## 隐藏与清理

“立即隐藏”会清空行末、阅读状态栏和虚拟阅读页，关闭本扩展的输入框或选择器，并遮住侧栏书名；保留代码标签和已保存进度。默认失焦也会隐藏。阅读和书架重启后均默认隐藏，需要分别主动恢复。

“从书架移除书籍”提供确认选项；“清除当前书籍记录”是直接清除当前书记录的旧版命令，没有额外确认。两者都保留原文件，但清除的阅读位置与书签没有撤销功能。数据边界见[本地数据与隐私](privacy.md)。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 代码旁边没有正文 | 打开代码文件并执行“开始随行阅读”；检查是否刚切走窗口触发了隐藏 |
| 设置 12 行却只看到几行 | 短文件或可见行不足时会缩减；翻页也只前进实际显示的行数 |
| 乱码 | 选择匹配的编码后重新打开书籍；GBK 文件可尝试 GB18030 |
| 章节目录为空 | 确认标题独占一行；特殊排版可改用全文搜索或百分比跳转 |
| 移动文件后打不开 | 放回原路径并刷新，或按新路径重新导入；记录不会自动合并 |
| 改了正文，进度消失 | 为防止字符偏移错位，内容变化会重置该书进度和书签 |
| 找不到旧的 Dev Notes 命令 | 新分类为 Dev Notes Reader；仍可搜索 `devNotes` 命令 ID |
| 重启后书架为空 | 若显示隐藏提示，点击“打开本地书架”即可 |
| 快捷键冲突 | 在“键盘快捷方式”中搜索 `devNotes`，重新绑定冲突按键 |

报告问题时，提供扩展版本、VS Code 版本、操作系统、阅读模式、复现步骤及预期/实际结果。优先附可公开的小段示例文本，避免提交整本原书、私人路径、用户存储或账户凭据。通过 [GitHub Issues](https://github.com/congim/dev-notes-reader/issues) 反馈。
