# 本地数据与隐私

本说明适用于 Dev Notes Reader 0.5.1 的扩展运行时。

## 读取与保存

扩展只读取用户主动选择或从书架恢复的本地文本文件。正文用于内存中的解码、分页、章节和搜索，不保存正文副本，不修改原书。

VS Code 的扩展全局存储中保存：

- 文件 URI、解码后正文的 SHA-256 摘要与字符长度；摘要用于检测内容变化。
- 当前阅读字符偏移、最近打开时间、当前书籍和阅读模式。
- 书架显示名称、书签名称与位置。

这些记录由 VS Code 管理，不写进当前项目。扩展没有把书架存储键加入 Settings Sync；阅读设置属于普通 VS Code 用户设置，是否同步取决于用户自身的 Settings Sync 配置。

随行阅读只使用编辑器装饰，不改写源码。注释页使用 `dev-notes:` 虚拟文档，不在磁盘创建阅读页文件。

## 网络与遥测

扩展运行时不主动请求网络、不采集遥测、不上传书籍或代码。开发时的 npm 安装、VS Code 测试工具下载，以及用户自行使用的 VS Code、操作系统和其他扩展，不属于本扩展的网络行为。

## 清理记录

从书架移除一本书会清除该书的文件记录、阅读进度、显示名称和书签，保留原文件及其他书籍。“清除当前书籍记录”直接清除当前书的记录。此类清除没有内置撤销，重新导入会作为没有进度的书籍处理。

关闭阅读页、立即隐藏或退出 VS Code 只隐藏界面，不清除书架记录。本扩展不承诺卸载后自动删除 VS Code 留存的数据；需要清理时，应先在扩展内移除相应书籍记录。

## 显示边界

隐藏会清空正文装饰、阅读状态栏、虚拟阅读页及本扩展的选择器，并遮住侧栏书名。它不会加密已保存的文件路径或书签，也不会清理操作系统文件选择历史、外部录屏或 VS Code 的外部历史记录。

正在显示的内容仍可能被看到或截图；拥有相应权限的其他扩展可能访问虚拟文档。此功能不提供安全隔离。反馈问题时请使用可公开的最小样本，避免附带私人书籍、真实用户存储或敏感路径。
